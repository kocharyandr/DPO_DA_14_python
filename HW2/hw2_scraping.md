# Задание: сбор данных с веб-сайта

## Цель

Найти сайт, на котором есть **карточки**: карточки товаров, услуг или предложений.

## Требования

1. **Извлечь информацию** с карточек. При этом необходимо понимать, какую конкретно часть информации вы достали (название, цена, дата, описание и т. д.).
2. **Сохранить информацию** для последующего анализа.
3. **Объём данных:** собранный набор должен быть достаточно большим.
4. **Формат результата:** информация должна быть собрана в таблицу и сохранена в файл **Excel** (`.xlsx`).

## Примеры

- **а)** С сайта магазина собрать информацию о товарах из одного или нескольких разделов.
- **б)** Выгрузить посты с комментариями из паблика VK, а также дополнительную информацию о них.
- **в)** Собрать информацию о мероприятиях или спектаклях с сайта продажи билетов.

> Подойдёт **любая** информация, пригодная для дальнейшего анализа.
> Сайт можно выбрать любой, который не защищён от извлечения информации :)

## Важно

При желании можно придумать **собственную идею** с использованием API или веб-скрейпинга.
